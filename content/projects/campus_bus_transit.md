# Campus Bus Transit System
A team built this bus system for a university campus. I worked on all three parts and was the main contributor to the driver app.

## My part

- The Flutter driver app: trip management and QR ticket scanning.
- The Flutter passenger app: a Widgetbook design system and a mock server so the apps could move before the API was ready.
- The .NET API: identity hardening, such as keyed backup-code lookup and an allow-list for JWT algorithms, with tests that guard it.

## Stack

Flutter, BLoC, Dio, Widgetbook, .NET 9, Express mock server.
